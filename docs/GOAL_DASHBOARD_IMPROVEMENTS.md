# 目标看板和预警系统优化说明

## 📋 改进概述

本次更新对目标看板和预警提醒系统进行了全面优化，简化了目标层级，增强了预警信息的清晰度。

## 🎯 主要改进

### 1. 目标体系简化

**之前**：五级目标体系
- 大目标 → 阶段目标 → 小目标 → 日目标 → 小时目标

**现在**：四级目标体系
- 大目标 → 阶段目标 → 小目标 → 日目标

**原因**：
- 小时目标过于细碎，实际使用中很少用到
- 简化后更符合实际工作场景
- 减少不必要的管理负担

### 2. 每日目标看板优化

#### 统计卡片（4个）
1. **当日目标**：显示今日目标总数
2. **当日完成**：显示已完成的目标数量
3. **进行中**：显示正在执行的目标数量
4. **连续打卡**：显示连续复盘天数

#### 任务清单优化
- 移除小时任务展开功能
- 简化任务卡片设计
- 清晰显示任务状态（已完成/待完成）
- 支持任务描述展示

### 3. 预警提醒系统重构

#### 延期目标预警 🔴
- 显示所有已过期但未完成的目标
- 清晰标注超期天数
- 显示目标层级标签（大目标/阶段目标/小目标/日目标）
- 支持滚动查看（超过5项时）

**示例**：
```
已延期 (2)
[大目标] 完成年度学习计划          超期5天
[阶段目标] 完成第一章学习          超期2天
```

#### 即将到期提醒 🟡
- 显示3天内即将到期的目标
- 清晰标注剩余天数（今天/剩1天/剩2天/剩3天）
- 显示目标层级标签
- 支持滚动查看

**示例**：
```
即将到期 (3)
[小目标] 完成课后练习              剩1天
[日目标] 提交项目报告              今天
[阶段目标] 完成模块测试            剩3天
```

#### 昨日未完成 🟠
- 显示昨天未完成的目标
- 帮助回顾和跟进
- 支持滚动查看

**示例**：
```
昨日未完成 (2)
[日目标] 整理学习笔记
[日目标] 回复客户邮件
```

#### 主推目标进度
- 显示前3个大目标的进度
- 显示剩余天数
- 进度条可视化

**示例**：
```
完成年度学习计划          65%
████████████░░░░░░░░
剩余 45 天
```

### 4. 视觉优化

#### 颜色编码
- 🔴 **红色**：延期目标（已过期）
- 🟡 **黄色**：即将到期（3天内）
- 🟠 **橙色**：昨日未完成
- 🟢 **绿色**：已完成
- 🔵 **蓝色**：进行中
- ⚪ **灰色**：未开始

#### 目标层级标签
- **大目标**：紫色标签
- **阶段目标**：蓝色标签
- **小目标**：绿色标签
- **日目标**：橙色标签

#### 交互优化
- 悬停效果增强
- 平滑过渡动画
- 清晰的视觉反馈

## 📊 数据计算逻辑

### 剩余天数计算
```typescript
const getDaysRemaining = (endDate: string) => {
  if (!endDate) return null;
  const end = parseISO(endDate);
  return differenceInDays(end, todayDate);
};
```

### 延期目标筛选
```typescript
const delayedGoals = goals.filter(g => {
  if (g.completed || g.status === 'archived') return false;
  const daysRemaining = getDaysRemaining(g.endDate);
  return daysRemaining !== null && daysRemaining < 0;
});
```

### 即将到期目标筛选
```typescript
const urgentGoals = goals.filter(g => {
  if (g.completed || g.status === 'archived') return false;
  const daysRemaining = getDaysRemaining(g.endDate);
  return daysRemaining !== null && daysRemaining >= 0 && daysRemaining <= 3;
});
```

## 📈 使用场景

### 场景1：查看今日任务
1. 登录系统，自动进入今日看板
2. 查看统计卡片，了解当日任务概况
3. 在任务清单中勾选完成的任务
4. 实时查看完成进度

### 场景2：处理延期任务
1. 查看预警提醒区域的"已延期"部分
2. 了解哪些任务已经超期
3. 根据优先级重新安排时间
4. 尽快完成延期任务

### 场景3：规划即将到期任务
1. 查看"即将到期"部分
2. 了解3天内需要完成的任务
3. 合理安排今日工作优先级
4. 确保按时完成

### 场景4：回顾昨日工作
1. 查看"昨日未完成"部分
2. 分析未完成原因
3. 决定是否需要重新安排
4. 在今日计划中跟进

## 💡 最佳实践

### 目标设置
1. **大目标**：设定季度或年度目标，明确方向
2. **阶段目标**：拆解为月度目标，设定里程碑
3. **小目标**：细化为周目标，可执行的任务
4. **日目标**：每日具体任务，可勾选完成

### 日常使用
1. **早晨**：查看今日看板，了解当日任务
2. **工作中**：勾选完成的任务，实时更新进度
3. **傍晚**：查看预警提醒，处理紧急任务
4. **晚间**：提交每日复盘，总结经验

### 预警处理
1. **延期任务**：立即处理或重新安排
2. **即将到期**：优先处理，确保按时完成
3. **昨日未完成**：分析原因，今日跟进
