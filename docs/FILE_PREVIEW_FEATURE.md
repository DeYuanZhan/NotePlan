# 文件打开和预览功能

## 📋 功能概述

NotePlan 现在支持上传文件的**在线打开和预览**功能，让用户可以直接在浏览器中查看上传的文件，而无需下载到本地。

## ✨ 主要特性

### 1. PDF 文件预览
- 📄 上传 PDF 文件后，点击"打开"按钮
- 在新标签页中直接预览 PDF 内容
- 支持浏览器原生 PDF 查看器功能（缩放、翻页、搜索等）

### 2. Word 文档处理
- 📝 上传 Word 文档（.doc, .docx）
- 点击"打开"按钮尝试在浏览器中查看
- 如果浏览器不支持，会自动下载文件

### 3. 双按钮设计
每个附件都提供两个操作按钮：
- **打开**（蓝色）：在新标签页中打开文件
- **下载**（灰色）：直接下载文件到本地

### 4. 文件信息展示
- 文件图标（📄 PDF / 📝 文档）
- 文件名称
- 文件类型
- 文件大小（KB）

## 🎯 使用方式

### 上传文件
1. 拖拽文件到编辑器
2. 或点击工具栏上传按钮
3. 或粘贴文件（Ctrl+V）

### 打开文件
1. 找到上传的附件块
2. 点击蓝色的"打开"按钮
3. 文件将在新标签页中打开

### 下载文件
1. 找到上传的附件块
2. 点击灰色的"下载"按钮
3. 文件将下载到本地

## 📊 支持的文件类型

### 可直接预览
- ✅ **PDF 文件**（.pdf）
  - 浏览器原生支持
  - 完整的 PDF 查看功能
  - 支持缩放、翻页、搜索

### 尝试打开
- ⚠️ **Word 文档**（.doc, .docx）
  - 取决于浏览器支持
  - 某些浏览器可能直接下载
  - 建议使用 Microsoft Office Online 或 Google Docs 打开

### 直接显示
- ✅ **图片文件**（.jpg, .png, .gif, .webp, .svg）
  - 直接在编辑器中显示
  - 支持点击放大查看

- ✅ **文本文件**（.txt, .md, .markdown）
  - 以代码块形式显示内容
  - 保持原始格式

- 按钮悬停时轻微上移

## 🔧 技术实现

### HTML 结构
```html
<div class="attachment-block">
  <div style="display: flex; align-items: center; gap: 8px;">
    <span style="font-size: 20px;">📄</span>
    <div style="flex: 1;">
      <div>文件名.pdf</div>
      <div>PDF · 256.50 KB</div>
    </div>
    <a href="data:..." target="_blank">打开</a>
    <a href="data:..." download="文件名.pdf">下载</a>
  </div>
</div>
```

### 关键特性
1. **target="_blank"**：在新标签页打开文件
2. **download 属性**：仅在下载按钮上使用
3. **event.stopPropagation()**：防止事件冒泡
4. **data URL**：使用 base64 编码存储文件

### 浏览器兼容性
- ✅ Chrome 60+
- ✅ Firefox 62+
- ✅ Safari 13+
- ✅ Edge 79+

## 💡 使用场景

### 场景1：查看 PDF 报告
1. 上传 PDF 文件到笔记
2. 点击"打开"按钮
3. 在新标签页中查看完整报告
4. 使用浏览器工具缩放、搜索

### 场景2：分享文档
1. 上传 Word 文档
2. 点击"打开"尝试预览
3. 如果无法预览，点击"下载"
4. 使用本地软件打开

### 场景3：批量管理文件
1. 上传多个文件
2. 每个文件都有独立的打开/下载按钮
3. 根据需要选择操作

## ⚠️ 注意事项

### 文件大小限制
- 建议单个文件不超过 10MB
- 大文件可能导致浏览器卡顿
- localStorage 容量限制（通常 5-10MB）

### 浏览器差异
- **PDF 预览**：所有现代浏览器都支持
- **Word 预览**：
  - Chrome：可能直接下载
  - Firefox：可能直接下载
  - 建议使用在线 Office 工具打开

### 数据安全
- 文件以 base64 格式存储在 localStorage
- 清除浏览器数据会丢失文件
- 重要文件建议备份
