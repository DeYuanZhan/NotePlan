# 智能提醒系统使用指南

## 📋 功能概述

NotePlan 现在提供完整的智能提醒系统，帮助用户及时关注目标的开始和截止时间，避免遗漏重要任务。

## ✨ 主要特性

### 1. 目标开始时间提醒
- **今日开始目标**：清晰展示今天开始的目标
- **即将开始目标**：展示即将开始的目标及倒计时
- **可配置提醒周期**：自定义提前几天开始提醒（1-30天）

### 2. 目标截止时间提醒
- **即将到期目标**：展示即将到期的目标及剩余天数
- **延期目标预警**：清晰标识已延期的目标
- **可配置提醒周期**：自定义提前几天截止提醒（1-30天）

### 3. 其他提醒
- **昨日未完成**：提醒昨天未完成的任务
- **今日任务清单**：展示今天的日目标

## 🎯 使用方式

### 配置提醒周期

1. 进入 **个人设置** 页面
2. 找到 **提醒设置** 区域
3. 配置以下选项：
   - **目标开始提醒**：拖动滑块设置提前几天提醒（默认3天）
   - **目标截止提醒**：拖动滑块设置提前几天提醒（默认3天）
   - **每日复盘提醒时间**：设置每天提醒复盘的时间（默认21:00）
4. 点击 **保存提醒设置**

### 查看提醒信息

在首页看板的 **预警提醒** 区域，可以看到：

#### 🔵 今日开始
- 显示今天开始的目标
- 标注目标层级（大目标/阶段目标/小目标/日目标）
- 提示"今天开始"

#### 🔷 即将开始
- 显示即将开始的目标（根据配置的提前天数）
- 显示倒计时（如"2天后开始"）
- 按目标层级分类展示

#### 🔴 已延期
- 显示已过期但未完成的目标
- 显示超期天数（如"超期5天"）
- 按紧急程度排序

#### 🟡 即将到期
- 显示即将到期的目标（根据配置的提前天数）
- 显示剩余天数（如"剩3天"或"今天"）
- 按紧急程度排序

#### 🟠 昨日未完成
- 显示昨天未完成的任务
- 帮助回顾和跟进

## 📊 提醒类型说明

### 按时间分类

| 提醒类型 | 触发条件 | 颜色标识 | 图标 |
|---------|---------|---------|------|
| 今日开始 | 目标开始日期 = 今天 | 🔵 蓝色 | ▶️ |
| 即将开始 | 距离开始日期 ≤ 配置天数 | 🔷 青色 | ⏰ |
| 已延期 | 目标结束日期 < 今天 | 🔴 红色 | ⚠️ |
| 即将到期 | 距离结束日期 ≤ 配置天数 | 🟡 黄色 | ⚠️ |
| 昨日未完成 | 昨天未完成的日目标 | 🟠 橙色 | ⚠️ |

### 按目标层级分类

每个提醒项都会显示目标层级标签：
- **大目标**：紫色标签
- **阶段目标**：蓝色标签
- **小目标**：绿色标签
- **日目标**：橙色标签

## 💡 使用场景

### 场景1：提前准备即将开始的目标
```
1. 查看"即将开始"提醒
2. 看到"完成项目报告"将在2天后开始
3. 提前准备相关资料
4. 确保按时开始执行
```

### 场景2：跟进延期目标
```
1. 查看"已延期"提醒
2. 看到"完成第一章学习"已超期5天
3. 分析延期原因
4. 重新安排时间或调整目标
```

### 场景3：关注即将到期目标
```
1. 查看"即将到期"提醒
2. 看到"提交项目报告"还剩3天
3. 评估当前进度
4. 加快执行速度确保按时完成
```

### 场景4：回顾昨日工作
```
1. 查看"昨日未完成"提醒
2. 分析未完成原因
3. 决定是否需要重新安排
4. 在今日计划中跟进
```

## 🔧 配置建议

### 提醒天数设置

#### 目标开始提醒
- **1-3天**：适合短期目标，快速响应
- **3-7天**：适合中期目标，充分准备
- **7-30天**：适合长期目标，提前规划

#### 目标截止提醒
- **1-3天**：适合紧急任务，最后冲刺
- **3-7天**：适合常规任务，保持节奏
- **7-30天**：适合重要任务，预留缓冲

### 每日复盘时间
- **20:00-21:00**：适合下班后复盘
- **21:00-22:00**：适合睡前复盘
- **根据个人作息调整**

## 📈 最佳实践

### 1. 定期检查提醒
- **早晨**：查看今日开始和即将开始的目标
- **工作中**：关注即将到期的目标
- **晚上**：处理延期和昨日未完成的目标

### 2. 合理设置提醒周期
- 根据工作节奏调整提醒天数
- 重要目标设置更长的提醒周期
- 紧急任务设置较短的提醒周期

### 3. 及时处理提醒
- **今日开始**：立即开始执行
- **即将开始**：提前准备资源
- **已延期**：分析原因，重新安排
- **即将到期**：加快进度或调整计划
- **昨日未完成**：评估是否需要继续

### 4. 结合复盘改进
- 每天查看提醒信息
- 晚间进行复盘总结
- 根据提醒调整明日计划
- 持续优化时间管理

## ⚠️ 注意事项

### 提醒准确性
- 提醒基于目标的开始和结束日期
- 确保正确设置目标的时间范围
- 定期检查和更新目标状态

### 提醒数量
- 每个类别最多显示5项
- 超过5项会显示"还有X项..."
- 可以滚动查看更多

### 配置保存
- 提醒设置保存在本地存储
- 清除浏览器数据会丢失配置
- 建议定期检查和调整配置
