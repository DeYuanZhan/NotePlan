# 今日看板目标同步说明

## 📋 功能概述

今日看板现在会自动同步并显示您在目标管理中创建的所有层级目标，包括大目标、阶段目标、小目标和日目标。

## ✨ 主要改进

### 1. 显示所有层级目标
- ✅ 大目标（长线目标）
- ✅ 阶段目标（中期目标）
- ✅ 小目标（短期目标）
- ✅ 日目标（单日任务）

### 2. 智能过滤逻辑
今日看板会显示以下目标：
- **今天开始的目标**：startDate 为今天
- **今天结束的目标**：endDate 为今天
- **今天进行中的目标**：startDate ≤ 今天 ≤ endDate

### 3. 清晰的目标信息
每个目标会显示：
- 🏷️ **层级标签**：大目标/阶段目标/小目标/日目标
- 📝 **目标名称**：清晰的目标描述
- 📅 **时间范围**：开始日期 ~ 结束日期
- ✅ **完成状态**：已完成/待完成
- 📄 **详细描述**：如果有的话

## 🎯 使用方式

### 方式一：创建今天开始的目标
1. 进入"目标管理"页面
2. 点击"新建大目标"或在现有目标下创建子目标
3. 设置开始日期为今天
4. 保存后，目标会自动显示在今日看板

### 方式二：创建今天结束的目标
1. 进入"目标管理"页面
2. 创建目标时设置结束日期为今天
3. 保存后，目标会自动显示在今日看板

### 方式三：创建跨天的目标
1. 创建目标时设置开始日期在今天之前
2. 设置结束日期在今天之后
3. 目标会作为"进行中"显示在今日看板

## 🔍 过滤规则详解

### 今日目标过滤逻辑
```typescript
const dailyGoals = goals.filter(g => {
  // 排除已归档的目标
  if (g.status === 'archived') return false;
  
  // 今天结束的目标
  if (g.endDate === today) return true;
  
  // 今天开始的目标
  if (g.startDate === today) return true;
  
  // 今天正在进行中的目标
  if (g.startDate && g.endDate) {
    const startDate = new Date(g.startDate);
    const endDate = new Date(g.endDate);
    const today = new Date();
    if (startDate <= today && endDate >= today) return true;
  }
  
  return false;
});
```

### 昨日未完成过滤逻辑

const yesterdayIncomplete = goals.filter(g => {

## ⚠️ 注意事项

### 1. 日期格式
- 使用 `YYYY-MM-DD` 格式
- 确保日期正确设置
- 避免留空（系统会自动填充）

### 2. 目标层级
- 大目标 → 阶段目标 → 小目标 → 日目标
- 每个层级都有对应的颜色标签
- 清晰区分不同层级的目标

### 3. 状态管理
- 未开始：灰色标签
- 进行中：蓝色标签
- 已完成：绿色标签
- 延期：红色标签
- 已归档：不显示

### 4. 进度计算
- 父级目标进度由子目标自动计算
- 勾选完成状态会向上更新
- 无需手动计算进度

## 🚀 常见问题

### Q1: 为什么我创建的目标没有显示在今日看板？
**A**: 请检查：
1. 目标的开始日期或结束日期是否包含今天
2. 目标是否被归档
3. 刷新页面查看最新状态

### Q2: 如何让我创建的大目标显示在今日看板？
**A**: 在创建大目标时，将开始日期设置为今天，或者将结束日期设置为今天。

### Q3: 为什么有些目标显示为"进行中"？
**A**: 如果目标的开始日期在今天之前，结束日期在今天之后，会显示为"进行中"。

### Q4: 如何查看目标的详细信息？
**A**: 点击目标卡片可以跳转到目标详情页，查看完整的层级结构和关联笔记。

### Q5: 昨日未完成的目标会一直显示吗？
**A**: 是的，昨日未完成的目标会在"昨日未完成"预警区域显示，提醒您跟进处理。
